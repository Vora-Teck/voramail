VoraMX API Documentation

Send reliable emails with a simple, developer-friendly API.

Introduction

VoraMX provides a clean, fast, and reliable email infrastructure for developers. Whether you're sending transactional emails or marketing campaigns, our API is designed to be simple yet powerful.

Base URL

https://api.voramx.com/v1

Quickstart

npm install @voramx/sdk

Authentication

All API requests require a Bearer token in the header.

Authorization: Bearer YOUR_API_KEY

Send Email

POST /v1/emails/send

fetch('https://api.voramx.com/v1/emails/send', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    to: "user@example.com",
    subject: "Welcome to VoraMX!",
    html: "<h1>Hello from VoraMX!</h1>",
    from: "noreply@yourdomain.com"
  })
});
import requests

response = requests.post(
    "https://api.voramx.com/v1/emails/send",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={"to": "user@example.com", "subject": "Welcome!", "html": "<h1>Hello!</h1>"}
)
print(response.json())
curl -X POST https://api.voramx.com/v1/emails/send \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to": "user@example.com", "subject": "Test", "html": "<p>Hello</p>"}'

Sample Response

{
  "success": true,
  "message_id": "msg_9k2mXvL8pQ",
  "status": "queued"
