WEBHOOKS

  • Webhook is used to receive updates on emails that are sent.

  • Kindly ensure that your webhook URL accepts POST requests
  • IP whitelisting ensure that only specific IP addresses can make API requests on your behalf
  • Separate multiple IPs with comma (,)
  • If no IP is provided, this means that all IPs will be allowed.
